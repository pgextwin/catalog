# Issue #112 — PGroonga 4.1.0 binary-to-rights candidate mapping (nonpublishing)

The earlier successful, original protected-main PGroonga rights Run [42913598150](https://github.com/pgextwin/catalog/actions/runs/42913598150) proved ZIP exact SHA256/size receipts for PostgreSQL 14–18, each with **43 DLL/EXE members and 20 files matching the old legal-name filter**. That is a historical filter count, not the complete number of bundled legal texts. The corrected filter below also captures BSD/GPL/LGPL basenames, yielding 24 candidates in the locally verified PG18 original. The path-exact review matrix retains every formal acceptance flag false.

`issue112_pgroonga_rights_join.py` takes the existing pinned-original rights-auditor output, verifies the original ZIP bytes again only in its own newly scoped job, rejects any changed 4.1.0 inventory, and creates one review row per binary with its path, byte length, SHA256, exact-path candidate component group and SHA256-linked candidate legal documents. No file-name substring, prefix, transitive license inheritance, or dynamically guessed library name grants legal acceptance. A missing or renamed binary fails the strict production matrix; unknown names in testing remain unattributed, never authorized.

The seven proposed *candidate* groups are PGroonga, Groonga, MeCab, xxHash, msgpack-c, llama.cpp/ggml and H3. The exact original package contains a named candidate for six groups; **xxHash still has no component-specific named license among the 24 captured documents**, despite shipping `bin/libxxhash.dll` and `bin/xxhsum.exe`. The **12 documents not linked by binary-name triage** include static dependencies, resource/asset licenses and the separately shipped groonga-log script license. They require separate source-build inspection, including Groonga's third-party bundles. MeCab and H3 and msgpack attribution require review of the entire named license/NOTICE set; a candidate match alone does not demonstrate a complete notice, licensing election, component version, or redistribution grant.
