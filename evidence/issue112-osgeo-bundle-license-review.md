# OSGeo license review for the PG15–18 Windows originals

This review applies to the exact SHA-256 and size pins in [the direct GET records](../external/direct-get.json). PostGIS is 3.6.2 for PG15 and 3.7.0 for PG16–18. Each archive contains pgRouting 4.0.1. The earlier [external-fetch audit](issue112-relaxed-external-fetch-20261117.json) records the original pins and the bundled component notices. The mappings below close the remaining GUI and runtime gaps for all four majors. Paths are relative to each ZIP bundle root. PE dates were used with producer metadata and MSYS2 package history as indicated.

## PG15 additional PROJ data and other packaged files

PG15's `proj.db` records PROJ 8.2.1, PROJ-data 1.8 and EPSG v10.041. PG16–18's `proj.db` records PROJ 9.8.1, PROJ-data 1.24 and EPSG v12.029. The PG15 data directory contains 189 datum-grid package members whose SHA-256 matches its packaged `files.geojson`. The license review mapped 187 members through the [PROJ-data 1.8.0 copyright and license table](https://github.com/OSGeo/PROJ-data/blob/1.8.0/copyright_and_licenses.csv), including the earlier `DK` and `nl_nsgi_naptrans2018.tif`, both CC-BY-4.0. The remaining two members are the [Hesse license notice](https://cdn.proj.org/de_hvbg_README.txt), listed as public domain in the [current index](https://github.com/OSGeo/PROJ-data/blob/master/copyright_and_licenses.csv), and the [GKU attribution notice for the CC-BY-4.0 Slovak grids](https://github.com/OSGeo/PROJ-data/blob/1.8.0/sk_gku/sk_gku_README.txt).

The other 17 PG15 entries in the directory are the 15 PROJ settings, table and schema files, the PROJ-data `files.geojson` index and the generated PROJ 8.2.1 `cache.db`. The SQLite cache holds downloaded-file metadata and zero grid chunks. The package-supplied settings and resource files follow the exact PROJ versions identified by the database. [PROJ 8.2.1 data](https://github.com/OSGeo/PROJ/tree/8.2.1/data), [PROJ 8.2.1 COPYING](https://github.com/OSGeo/PROJ/blob/8.2.1/COPYING), [PROJ 9.8.1 data](https://github.com/OSGeo/PROJ/tree/9.8.1/data).

The four `bin/mapconfig*.xml` files and `bin/{AUTHORS,CODE_OF_CONDUCT,CONTRIBUTING}.md` accompany osm2pgrouting 3.0.0 at [commit 785a13e](https://github.com/pgRouting/osm2pgrouting/tree/785a13e5077c8966b2bac5ede72d88c394139a23). Its bundled `bin/COPYING` matches the accompanying component notice. The shell tools `bin/pgtopo_export` and `bin/pgtopo_import`, GUI `shp2pgsql-gui.exe`, and the PostGIS documentation, utility and SQL trees are PostGIS files at the corresponding bundle release. [PostGIS 3.6.2 license](https://github.com/postgis/postgis/blob/3.6.2/LICENSE.TXT), [PostGIS 3.7.0 license](https://github.com/postgis/postgis/blob/3.7.0/LICENSE.TXT). The pgRouting 4.0.1 version in all four packaged controls maps to the [pgRouting 4.0.1 notice](https://github.com/pgRouting/pgrouting/blob/v4.0.1/LICENSE).
